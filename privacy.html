Privacy Policy

Last updated: October 10, 2026

This policy covers AI Jissoku Uploader (the "Tool"), a private publishing tool operated by the owner of the YouTube channel AI Jissoku-shitsu (@ai-jissoku).

YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the Tool

The Tool is used only by the channel owner, signed in with the channel owner's own Google account through OAuth 2.0. It has no public sign-up and is not offered to other users.

What data is accessed

  • OAuth scopes: youtube.upload and youtube.force-ssl to upload the channel's own videos, captions and thumbnails, update or delete the channel's own videos, and post comments as the channel; yt-analytics.readonly and youtube.readonly to view the channel's own YouTube Analytics reports (views, watch time) so the owner can see which topics viewers find useful; monitoring.read to read the project's own API quota usage.
  • The Tool reads only the channel owner's own video metadata and analytics (for example to confirm an upload finished). It does not access, collect or store data about viewers or any other YouTube user.

How data is stored and shared

The OAuth token, upload records (video ID, upload time) and cached analytics/metadata for the owner's own channel are stored only on the channel owner's computer. Nothing is sold, shared with third parties, or used for advertising. No cookies or tracking are used on this website.

Deletion and revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored token stops working and is deleted together with the local upload records within 7 days. To ask about or request deletion of any data, email aijissoku@gmail.com.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
